On the display computer
1
Run the single dependency installation command from the project README. It includes Google Chrome, Openbox, LightDM, SSH, logging and display tools. The script checks dependencies before launching.
2
Copy the complete dist contents into ~/Desktop/kiosk-url/ and keep its subfolders. Run the launcher from kiosk/; keep local JSON and the wallpaper beside it. It checks the public repository for script updates at startup. Run without a JSON argument to download the machine hostname JSON, falling back to local default.json. Test inside X11/Openbox: chmod +x url-kiosk.sh && ./url-kiosk.sh kiosk.json.
3
For hostname-based startup: ./url-kiosk.sh --no-update --install-autostart. Openbox then runs the launcher without JSON arguments. Supply a JSON during installation only if you want a fixed boot.json.
4
For unattended startup, run bash ~/Desktop/kiosk-url/setup/install-kiosk-boot.sh without a JSON on Ubuntu. It finds the sibling kiosk/ folder automatically. It configures LightDM automatic login to Openbox. Administrator authentication is required during installation only.


Readable diagnostics
Every run records timestamps, display names, GPU outputs and URLs. Errors are grouped by where they were observed; this does not prove their root cause.
CategoryWhat it records
WEBSITEConsole errors/warnings and uncaught JavaScript exceptions.
NETWORKHTTP 4xx/5xx and failed requests, including resource URLs.
BROWSER / GPUChrome process messages and graphics warnings.
SYSTEMLauncher, monitor connections, navigation and window placement.
Each run writes one log, such as url-kiosk_2026-10-18_11-53-00.log, directly beside url-kiosk.sh, independently of the terminal working directory. The exact path is printed at launch. Console messages, network failures, Chrome/GPU output and system events share this file. Normal console output is retained in the file; repeated terminal messages are grouped for 30 seconds.
[2026-10-18 11:55:01] 🌐 ERROR WEBSITE D1 [DP-5]
    Uncaught TypeError: example
    URL: https://example.com

[2026-10-18 11:55:02] 📡 ERROR NETWORK D2 [HDMI-0]
    Request failed
    URL: https://example.org
Each entry has an emoji, a local timestamp, a separate message and URL, and a blank line before the next entry. Details include full event data. Logs start with the result of DISPLAY=:0 XAUTHORITY="$HOME/.Xauthority" xrandr --query. Files do not rotate; remove old runs as needed.
Monitoring attaches after Chrome starts loading the configured URL and includes attached frame/worker targets where Chrome supports it. Close existing kiosk Chrome windows before launching. Browser diagnostics use loopback-only debugging ports. Logs can contain URLs and console data. Old run logs remain until you remove them.
The optional local Python server stores the SQLite library on this computer. Only configurations marked Publish are exported to the public distribution. Browser drafts stay in this browser.
